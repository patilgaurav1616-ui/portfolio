# Gaurav Patil — Personal Portfolio

An editorial, high-end developer portfolio recreated with 100% visual fidelity to the master design reference. Built with React 18, Vite, Tailwind CSS, and custom typography pairings.

## Features
- **Master Hero Section**: Exact 1:1 visual recreation matching warm ivory (`#F5F2EC`), editorial serif (`Bodoni Moda`), modern bold sans-serif (`Syne`), studio monochrome portrait, 3D metallic ribbon loop, and architectural guidelines.
- **Dark / Light Mode**: Functional persistent theme switch (Sun ☀ / Moon ☾).
- **Verified Resume Integration**:
  - **About**: Academic life at MPSTME, NMIMS University, philosophy, and community volunteering at Matimand Mulanche Balgruh, Shirpur.
  - **Projects**: QueryMind (Text-to-SQL RAG), Retail Consumer Behavior Analysis (Power BI), AI-Powered Learning & Skill Exchange (MERN + Gemini AI).
  - **Expertise**: AI & GenAI, Data Analytics & BI, Full Stack Development, Core CS, and Tools.
  - **Education**: MPSTME NMIMS, R.C. Patel College, Randhe School, plus 7 verified certifications (IIT Bombay, Coursera, Apna College, HackerRank, SIH 2025).
  - **Contact**: Quick-copy email/phone cards, message form, and social links.
  - **Resume Modal**: Printable CV with 1-click Save as PDF.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
